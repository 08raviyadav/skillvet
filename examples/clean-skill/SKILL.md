# PDF Summarizer

Drop a PDF into the conversation and get a clean summary.

## How it works

1. Extract the text from the PDF locally.
2. Split it into sections and summarize each one.
3. Return the summary with page references.

## Rules

- Work only on files the user provides in this conversation.
- Never upload documents anywhere.
- Keep summaries factual; quote exact figures with their page numbers.
